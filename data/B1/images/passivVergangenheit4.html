Заменитель Пример с Passiv Пример с заменителем
sein + прилагательное с суффикса -bar, -abel, -lich
(заменяют Passiv с модальным глаголом können)

Die Aufgabe kann gemacht werden. — Задание может быть выполнено.

Das Angebot kann akzeptiert werden. — Предложение может быть принято.

Die Schrift kann gut gelesen werden. — Почерк можно хорошо разобрать (прочитать).

Die Aufgabe ist machbar. — Задание выполнимо.

Das Angebot ist akzeptabel. — Предложение приемлемо.

Die Schrift ist gut leserlich. — Почерк разборчивый.

Обобщим:

Indikativ:
Ich kann das Problem nicht lösen. — Я не могу решить проблему.
Passiv:
Das Problem kann nicht gelöst werden. — Проблема не может быть решена.
Заменители
man
Man kann das Problem nicht lösen. — Проблему нельзя решить.
sich lassen
Das Problem lässt sich nicht lösen. — Проблема не решается.
sein + zu + Infinitiv
Das Problem ist nicht zu lösen. — Проблему нельзя решить.
прилагательное
Das Problem ist nicht lösbar. — Проблема нерешаема.
