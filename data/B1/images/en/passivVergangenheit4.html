Substitute Example with Passiv Example with substitute
sein + adjective with suffixes -bar, -abel, -lich
(replaces Passiv with the modal verb können)

Die Aufgabe kann gemacht werden. — The task can be done.

Das Angebot kann akzeptiert werden. — The offer can be accepted.

Die Schrift kann gut gelesen werden. — The handwriting can be read easily.

Die Aufgabe ist machbar. — The task is doable.

Das Angebot ist akzeptabel. — The offer is acceptable.

Die Schrift ist gut leserlich. — The handwriting is legible.

To sum up:

Indikativ:
Ich kann das Problem nicht lösen. — I cannot solve the problem.
Passiv:
Das Problem kann nicht gelöst werden. — The problem cannot be solved.
Substitutes
man
Man kann das Problem nicht lösen. — The problem cannot be solved.
sich lassen
Das Problem lässt sich nicht lösen. — The problem cannot be solved.
sein + zu + Infinitiv
Das Problem ist nicht zu lösen. — The problem cannot be solved.
adjective
Das Problem ist nicht lösbar. — The problem is unsolvable.
